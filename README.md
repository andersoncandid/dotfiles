# My dotfiles

> [!NOTE]
> **About the configuration**
> The i3 configuration uses XFCE components:
> - `polkit-gnome-authentication-agent`
> - `light-locker`
> - `xfce4-screenshooter`
> - `Thunar`

#### **usage:**

- clone this repository
```shell
cd ~/dotfiles
stow <package name>
```
<br>
